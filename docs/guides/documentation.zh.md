# 双语文档

[English](documentation.md)

英文是默认显示语言。英文与简体中文具有同等效力：可以先修正任一版本，但须在同一次贡献中同步两者。

## 范围与配对

`docs-i18n.yaml` 定义最终受控范围和明确排除的执行文档。技能、智能体指令、执行提示词、机器模板、测试夹具和下游研究材料不参与配对。发现文件时不跟随符号链接。

英文 `name.md`、中文 `name.zh.md` 和同目录的 `name.i18n.yaml` 构成一个整体。创建、重命名或删除时须同时处理三者并更新引用。现有未翻译文档列入临时迁移积压清单。仅编辑这些文档无需完整翻译。新文档不得加入清单；已迁移文档不得退回。迁移完成后移除这一机制。

## 贡献者命令

在仓库根目录执行命令：

```sh
pnpm docs:i18n:list
pnpm docs:i18n:check
pnpm docs:i18n:check -- README.md
pnpm docs:i18n:record -- README.md
pnpm docs:i18n:record --help
```

pnpm 会传递路径，可选的分隔符不影响传参。全量检查所有已启用的文档对，只读且遇到缺失文件或过期确认时失败。指定名称可缩小配对检查范围；积压清单的合法性仍是仓库级约束。记录必须明确指定英文路径，只写入指定记录，绝不执行翻译。

## 审查与记录

增量翻译受影响内容，审查含义和术语，然后明确记录已审查的文档对并检查整个文档集。结构兼容但未翻译的对应文档也能成功记录；哈希无法证明翻译的准确性、完整性或可读性。贡献者负责语义确认。

章节按标题出现顺序对应。键使用英文标题的 slug 路径，重复时追加 `~2` 等后缀。每种语言分别对自身编写的顶层块按换行连接后计算 SHA-256，取前 16 个十六进制字符。围栏代码不计入正文哈希。不支持排除生成的正文。仅修改正文可保持无关条目不变；标题或层级变化可能改变多个键。

检查和记录都会拒绝标题深度或顺序、列表类型、有序列表起始编号或条目数量、以及表格维度不一致的文档。代码块的类型、围栏元数据和正文必须逐字节一致，包括注释和示例输出。请在代码围栏外翻译说明。插入或重排重复标题可能改变多个记录键；不使用手工分配的章节标识。

记录格式遵循已检查的 DeepSeek Harness 版本 `f3803c96974ad4a94195fb97e5c637e9c2a3afe3`。已审查其 MIT 许可证；本工具独立实现。记录是规范有序的 YAML 映射，分别保存 `en` 和 `zh` 哈希。两者既不要求相同，也不要求不同。

## 导航

在主标题后立即放置指向另一语言版本的链接。指向已配对文档的链接须选择读者所用语言的对应目标，并保留查询字符串和片段；被排除或仍在待迁移清单中的目标保持原有路径。本地目标必须存在。引用章节时，两个版本须在各自翻译的标题前提供相同的显式英文锚点，例如 `<a id="navigation"></a>`。这一共享锚点约定是 paper-craft 的适配；上游保留片段，但不会自动映射翻译后的标题。重命名或删除配对文档时应更新所有引用。记录命令会先拒绝无效导航，再写入确认记录。

## 编辑与恢复

使用[翻译用语](translation-terminology.md)和[架构术语表](../../GLOSSARY.zh.md)。编辑任务负责增量翻译和语义审阅；无需单独的翻译调度器或强制翻译 skill。CI 执行确定性检查，不调用模型，也不更新记录。

可以编辑任一语言，只同步对应文档中受影响的内容，确认含义后，再记录明确指定的配对。例如，审阅原则文档的变更后：

```sh
pnpm docs:i18n:record -- CONSTITUTION.md
pnpm docs:i18n:check -- CONSTITUTION.md
pnpm docs:check
pnpm docs:check --help
```

单侧编辑会使确认记录过期。修正对应版本并审阅两侧后，才能重新记录。遇到结构或导航错误时，先修复报告的文件与章节；记录操作不能覆盖这些错误。三件套缺失时，应恢复缺失文件，或完成整个重命名、删除及入站链接更新。保持无关记录不变。聚合命令检查所有已启用配对；范围内工作使用指定文档的检查命令。所有命令均接受 `--help`。

第二批迁移包括[原则](../../CONSTITUTION.zh.md)、[架构](../../DESIGN.zh.md)和术语表。其余待办文档仍可编辑，无需完整翻译。迁移时添加对应版本、移除待办项、审阅并记录配对。待办清空后，删除临时初始迁移机制。仅英文的 agent 指导链接到此文档，不复制这些规则。
