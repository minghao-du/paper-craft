# Paper Craft

Research organization and agent workflow terminology.

## Language

**Project**:
A research project grouping related repositories. A Project is distinct from a Fleet.
_Avoid_: Fleet as a synonym for Project

**Fleet**:
A workflow unit defined by one authoritative configuration, comprising a Conductor, its configured EPIC Agent and a pool of working directories. Work in a Fleet may also originate directly from the user without an EPIC.
_Avoid_: Project as a synonym for Fleet
